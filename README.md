# GrainDesk · 骨料图像筛级

GrainDesk 在本机检查单张背照铺粒图。用等面积圆径给完整颗粒分档，同时保留原片、剔除情况、标定和留样的粒号清单。

## 启动

运行 `./start.sh`，打开 [筛级工作台](http://127.0.0.1:19898/)。设置 `GRAINDESK_PORT` 可改本地端口。运行 `./start.sh stop` 停止容器，数据保存在命名卷。已安装锁定依赖时，也可用 `python -B -m grain_desk` 直接启动。

## 一次检查

1. 打开「河湾」合成练习，或导入单张 PNG、JPEG 或 TIFF。铺粒应比背景暗，标尺放在与颗粒相同的平面。
2. 用两个角点画检查框并避开标尺。切换原片、二值图和分档图，调整阈值和最小面积后重算。
3. 用户输入标尺长度，再点原片上两端。设置递增孔径，按等面积圆径展示各档的粒数。未标定的照片仍可复核原片像素面积。
4. 点颗粒或点列表定位，查看面积、直径和档位。可排除误识别的颗粒或恢复计入。截到检查框边缘的颗粒以红色显示，从汇总中排除。
5. 选中一粒已标定、边缘完整且仍计入的颗粒，在「方筛孔试摆」里按当前孔径逐档试正方形筛孔。摆法是整度刻线，原向为 0°；每档居中摆放，同一角度下两边同时容得下才算通过，贴边的孔边会标出，容不下的档也会列出所需最小孔径。小孔和大一档的摆法都会给出孔径、转角与最近孔边的净余量，可任选其一采用；采用后只重分这一粒，其余颗粒照旧。
6. 保存可继续编辑的检查设置，或封存命名留样。留样会记下采用的孔径、转角和净余量，重开仍可核对；颗粒 CSV 的 class_upper_mm 也按采用的孔径出档。
7. 照片准备可处理多帧影像，并把已生成的准备结果送为一张新的铺粒原片。

每张原片短边至少 20 像素，总量最多 320 万像素、12 MiB。单次检查最多列出 600 粒。16 位图以 8 位灰度阈值检查，透明区域按白底处理。当前分档为二维的等面积圆径读数。练习图为合成素材，可直接检验原片坐标和尺长。照片准备的多帧预算由该工作区单独限制。
